## 2. スマートシステムのパラメータ設定値（茎ブロッコリー専用）

| 項目 | 設定値 | 動作内容・理由 |
| :--- | :--- | :--- |
| **自動給水（水分判定）** | **毎朝 6:30 に判定**<br>土壌水分 **＜ 35%** で作動 | 涼しい朝に判定。葉が巨大化して水を欲しがるため、35%で早めに給水。 |
| **バルブ開放時間** | **90 秒間** | 重力点滴で約400〜500mlの雨水が根元にじわじわ浸透。 |
| **追肥検知（EC判定）** | **給水15分後に測定**<br>土壌EC **＜ 0.5 mS/cm** | 土が湿った状態で正確に肥料濃度を測定。 |
| **追肥アラート通知** | 金曜の夜 または 土曜朝 | 「茎ブロッコリーの肥料が少なくなっています。今週末にスプーン1杯の化成肥料をあげてください」とDiscord通知。 |
| **カメラ定時撮影** | **毎朝 8:00** | 朝の光で2畳全体の写真を撮影し、写真付きレポートをDiscordへ送信。 |

### ★ 唯一の重要作業：10月下旬の「摘芯（てっぺんカット）」
* 植え付けから約50〜60日後、中心に**500円玉くらいの大きさのブロッコリー（頂花蕾）**ができます。
* これをハサミで思い切ってチョキンと切り落とします（この頭も美味しく食べられます）。
* **カットすることで植物のスイッチが切り替わり、脇から20〜30本以上の茎ブロッコリー（側花蕾）が一気に生え始めます**。

## 4. 週末の極上ペア食卓レシピ

茎ブロッコリーは、**茎の部分がアスパラガスのように柔らかく、甘みが強い**のが最高の特徴です。

1. **「採れたて1分半ボイル ＋ 粗塩＆オリーブオイル」**:
   * お湯に塩を少し入れ、1分半だけサッと茹でる。採れたてのシャキシャキ感と強い甘みをダイレクトに味わう。
2. **「豚バラ肉巻きブロッコリーの甘辛グリル」**:
   * 収穫したスティックに豚バラ肉をくるくる巻き、フライパンで焼いて醤油・みりん・砂糖で味付け。週末のビールが進むメインおかずに。
3. **「採れたてブロッコリーとアンチョビのペペロンチーノ」**:
   * パスタが茹で上がる直前の鍋にブロッコリーを放り込み、ニンニク・アンチョビ・オリーブオイルで和えるだけの贅沢ランチ。
