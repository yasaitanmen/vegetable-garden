# 🌿 Vegetable Garden Project (スマート週末家庭菜園)

自宅前の限られたスペースで、平日は「手間いらず・枯らさない安心」、週末は「2人で楽しむリフレッシュと旬の味覚」を実現する、スマート家庭菜園プロジェクトです。

---

## 🎯 プロジェクト概要 & ペルソナ

* **ターゲットペルソナ**: 
  * 会社員と主婦の2人家族
  * スタイル: 週末農家（作業時間は土日の数時間程度）
  * 目的: 季節の旬の野菜を育て、楽をしつつ収穫の喜びと採れたての食卓を楽しむ
* **栽培環境**:
  * 設置場所: 自宅前 約2畳スペース（約 1.8m × 1.8m）
  * 容器: 7ガロン（約26〜30L）不織布プランター × 6個
* **コアコンセプト**:
  * **平日（月〜金）**: 完全自動給水と見守りにより「ノーメンテ・ゼロプレッシャー」
  * **週末（土・日）**: 迷わず作業できるToDoガイドと、2人で楽しむ収穫＆旬の食卓

## ⚡ 最新システムアーキテクチャ (IoT・ハードウェア・通信)

雨水タンクの重力差を利用し、4G携帯回線と広角カメラ・土壌水分/ECセンサーを統合した最新のアーキテクチャです。

```mermaid
graph TD
    classDef pwr fill:#fef6e4,stroke:#d97706,stroke-width:2px,color:#78350f,font-size:14px;
    classDef ctl fill:#e8f4f8,stroke:#2b7a9e,stroke-width:2px,color:#1a3c4d,font-size:14px;
    classDef water fill:#eef9e8,stroke:#4a852c,stroke-width:2px,color:#254616,font-size:14px;
    classDef usr fill:#f3e8ff,stroke:#7c3aed,stroke-width:2px,color:#4c1d95,font-size:14px;

    AC["自宅 屋外コンセント (AC100V)"]:::pwr --> Adapt["12V 3A 防水ACアダプター<br/>（バッテリーレス・炎天下リスク0%）"]:::pwr

    subgraph 制御・通信・カメラユニット【防水BOX（日陰配置）】
        Adapt --> Box["屋外IP65防水BOX"]:::ctl
        Box --> SIM_MCU["4G/LTEマイコン (LilyGO T-SIM7600)<br/>（格安IoT SIM直挿し・ルーター不要）"]:::ctl
        Box --> CAM["広角カメラ (ESP32-CAM)<br/>（200万画素・2畳全体を見下ろす）"]:::ctl
        Box --> Sensor["RS485 土壌 水分・ECセンサー<br/>（水分 ＆ 肥料EC ＆ 温度を同時測定）"]:::ctl
        Box --> Relay["バルブ制御リレー"]:::ctl
    end

    subgraph 給水ユニット【雨水タンク重力給水】
        Rain["雨水タンク（底上げ設置）"]:::water --> Filter["120メッシュ ディスクフィルター<br/>（砂埃・ゴミを完全除去）"]:::water
        Filter --> Valve["12V 電動ボールバルブ<br/>（ゼロ水圧対応・水圧ロス0）"]:::water
        Relay ===|"給水時に通電して全開"| Valve
        Valve --> Drip["6鉢の7ガロン不織布プランターへ点滴給水"]:::water
    end

    SIM_MCU <==>|"4G 携帯回線"| Phone["📱 夫婦2人のスマートフォン<br/>・毎朝8時に『今朝の菜園写真📸』<br/>・肥料切れ時に『追肥アラート』<br/>・いつでも手動給水"]:::usr
```

### システムの3大特徴
1. **雨水重力給水 ＆ ゼロ水圧バルブ**: ポンプを使わず、底上げした雨水タンクの重力差と電動ボールバルブで無駄なく給水。水道代0円＆ゴミ詰まりなし。
2. **4G携帯回線 ＆ 広角見守りカメラ**: 自宅Wi-Fiルーター不要。SIM直挿しマイコンで毎朝の写真をLINEへ自動送信。
3. **土壌 水分・ECセンサーによる完全管理**: 水分低下で「自動給水」、肥料切れで「週末追肥アラート」を自動通知。
